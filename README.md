# m7mddz File Manager (PS4)

مدير ملفات لجهاز PS4 معدّل. التطبيق يشغّل سيرفر صغير على الجهاز، وأنت تفتح الواجهة من المتصفح (جوال أو كمبيوتر على نفس الواي فاي) وتتحكم في ملفات الألعاب والنظام.

## المزايا
- تصفح كل المجلدات (`/user`, `/system_data`, `/data`, `/mnt/usb0` وغيرها)
- رفع ملفات وتحميل ملفات (بدون حد للحجم، بالـ streaming)
- إعادة تسمية، نسخ، نقل، حذف (يشمل المجلدات)، مجلد جديد
- بحث سريع داخل المجلد
- واجهة عربية داكنة مع أيقونة m7mddz
- حماية برقم PIN عشوائي من 4 أرقام يظهر على شاشة PS4 عند التشغيل

## أسهل طريقة للحصول على PKG (بدون تثبيت أي شي)
1. سوّ حساب على github.com وأنشئ مستودع جديد (Repository).
2. ارفع كل محتويات هذا المشروع، **مع مجلد `.github`** (مهم).
3. افتح تبويب **Actions** ← **Build PS4 PKG** ← **Run workflow**.
4. بعد دقيقتين تقريباً ينزل لك ملف PKG من قسم **Artifacts** (الحجم صغير جداً، أقل بكثير من 90 ميغا).

## البناء (على كمبيوتر)
1. ثبّت OpenOrbis PS4 Toolchain: https://github.com/OpenOrbis/OpenOrbis-PS4-Toolchain
2. اضبط المتغير: `export OO_PS4_TOOLCHAIN=/path/to/OpenOrbis-PS4-Toolchain`
3. داخل مجلد المشروع شغّل: `make`
4. ملف PKG يطلع داخل مجلد `build/`

## التثبيت والتشغيل
1. انسخ ملف PKG إلى فلاش USB (أو ثبّته عبر أداة الـ PKG Installer عندك مثل GoldHEN / Remote Package Installer).
2. شغّل التطبيق **m7mddz** من الشاشة الرئيسية.
3. يظهر إشعار فيه الـ PIN. شوف عنوان الـ PS4 من: الإعدادات ← الشبكة ← عرض حالة الاتصال.
4. افتح في المتصفح: `http://عنوان-PS4:8080` وأدخل الـ PIN.

## اختبار بدون PS4
`make host && ./build/m7host` ثم افتح `http://127.0.0.1:8080` (الـ PIN يطلع في الطرفية).

## ملاحظات مهمة
- لم أجرّب التطبيق على جهاز PS4 حقيقي. اختبرت منطق السيرفر والملفات على لينكس فقط.
- الوصول لمجلدات النظام يعتمد على صلاحيات الجيلبريك عندك (GoldHEN أو غيره). إذا ظهر "cannot open folder" لمجلد معين فهذا حد من الصلاحيات وليس من التطبيق.
- الواجهة مفتوحة على شبكتك المحلية فقط، لا تفتح المنفذ 8080 على الإنترنت.
- احذر من حذف ملفات `/system` أو `/system_data`، فقد يتعطل الجهاز.
- لا أعرف إصدار PS4 رقم 13.52 (آخر ما أعرفه 12.52). تأكد من إصدار الفيرموير الفعلي ومن وجود جيلبريك يدعمه قبل التجربة. التطبيق نفسه لا يعتمد على رقم الفيرموير.
